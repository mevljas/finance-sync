# `/retro` — Agent Retrospective Skill

After completing a feature or resolving a bug:
1. Identify any non-obvious API quirks, parser edge cases, or tooling pitfalls encountered during implementation.
2. Codify those lessons into `AGENTS.md`, `docs/GLOSSARY.md`, or a new ADR in `docs/adr/` so future agent sessions never repeat the same mistake.
