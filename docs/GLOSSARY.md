# Ubiquitous Domain Glossary (`docs/GLOSSARY.md`)

| Term | Definition |
| :--- | :--- |
| **Activity Flex Query** | An XML statement configured in Interactive Brokers Account Management containing `Trades`, `CashTransactions`, `OpenPositions`, and `CashReport` sections. |
| **Two-Step Flex Polling** | The IBKR Flex Web Service protocol: Step 1 calls `SendRequest` to obtain a `<ReferenceCode>` and `<Url>`; Step 2 waits 10 seconds and calls `GetStatement` with the reference code to download the generated XML. |
| **Stock Buy Note** | The standardized BudgetBakers `note` format required for stock/ETF purchases, embedding executed shares, ISIN, symbol/name, and execution price: `BUY <shares> sh <ISIN> (<symbol>) @ <price> <currency>`. |
| **Balance Formula** | BudgetBakers Wallet's invariant for standard/investment accounts: `currentBalance = initial + totalIncomes - totalExpenses`. Updating an account's live market value requires patching `initialBalance = target_value - totalIncomes + totalExpenses`. |
| **Saveback** | Trade Republic's 1% card cashback reward program that automatically invests earned bonus income into a selected savings plan security. Modeled as bonus `income` (`Interest, dividends`) on `BB_TR_WEALTH_ACCOUNT_ID`. |
| **Savings Plan (`Sparplan`)** | Recurring automated ETF/stock investment in Trade Republic. Deducts cash (`expense` on `BB_TR_CASH_ACCOUNT_ID`) and logs the security purchase with shares, ISIN, and price (`expense` on `BB_TR_WEALTH_ACCOUNT_ID`). |
| **Seen Record Hash** | The deterministic SHA-256 primary key stored in SQLite `seen_records`: `sha256(broker + external_id + timestamp + f"{float(amount):.2f}")`. |
| **Backfill Seeding** | The initial startup routine that matches existing records in BudgetBakers Wallet (`±3 days` + exact amount) and seeds their SHA-256 hashes into SQLite `seen_records` so full history can be synced without creating duplicates. |
| **Low-Entropy Synthetic Fixture** | Zero-padded dummy identifiers (`"000000000000000001"`, `"U00000000"`) used in tests and `.env.example` so secret scanners (`gitleaks`) never flag test data for high Shannon entropy (see ADR-0004). |
| **Dry-Run Mode** | Read-only execution mode (`DRY_RUN=true` or `--dry-run`) that performs live or mock ingestion and read-only BudgetBakers `GET` queries while blocking all BudgetBakers mutations (`POST`, `DELETE`, `PATCH`) and all SQLite writes (`seen_records`, `sync_metadata`) (see ADR-0005). |
| **Dry-Run Preview Report** | Structured JSON file emitted via `--dry-run-output <path.json>` containing sync summary counts and the exact payloads (`would_create_records`, `would_delete_record_ids`, `would_patch_accounts`) that a live sync cycle would execute. |
| **FX Conversion Trade (`assetCategory="CASH"`)** | An automatic currency conversion entry (such as `EUR.USD`) emitted inside IBKR's `<Trades>` XML section when funding foreign-currency trades or sweeping foreign dividends. Excluded by `parse_flex_xml` so only real security trades are logged in Wallet (see ADR-0006). |
| **Account Record Purge (`--purge-account-records`)** | CLI flag on `ibkr_worker` and `tr_worker` that deletes all existing REST records and CouchDB `-AssetTransaction` documents on the target account before syncing (see ADR-0006). |
| **Targeted Deletion File (`--delete-file`)** | CLI flag accepting a local gitignored JSON file (`{"record_ids": [...], "couchdb_doc_ids": [...]}`) to delete specific legacy REST records or CouchDB `-AssetTransaction` documents without hardcoding user-specific rules in the repository. |
| **CouchDB Stock Asset (`-StocksFundsAsset_<uuid>`)** | Native BudgetBakers CouchDB document defining a security's symbol, exchange (`exchangeCode`), and currency (`currencyCode`) so Wallet's built-in Investments module can track its daily market price (see ADR-0007). |
| **CouchDB Asset Transaction (`-AssetTransaction_<uuid>`)** | Native BudgetBakers CouchDB document recording a stock/ETF buy (`transactionType: 0`) or sell (`transactionType: 1`) on an investment account (`-Account_<uuid>`), storing `quantity`, `price` (in quote currency cents), and `cashAmount` (in EUR cents) (see ADR-0007). |
| **Paired Transfer (`pairingMode: "new"`)** | BudgetBakers REST `Record` payload field (`transfer: {"pairingMode": "new", "accountId": "<uuid>"}`, with `categoryId` omitted) that links an outgoing Savings Plan deduction on `BB_TR_CASH_ACCOUNT_ID` to an automatic incoming transfer on `BB_TR_WEALTH_ACCOUNT_ID` (see ADR-0007). |
| **Historical Flex XML Import (`--xml-file`)** | `ibkr_worker` CLI flag accepting one or more `.xml` files or a directory of `*.xml` files exported from the IBKR Portal, merging and deduplicating `Trades` and `CashTransactions` chronologically while taking `OpenPositions` and `ending_cash` from the latest statement (see ADR-0008). |
